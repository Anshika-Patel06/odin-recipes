# Odin Recipes

A simple multi-page recipe website built with plain HTML as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## About

Odin Recipes is a small collection of recipes. The home page lists every recipe as a link, and each recipe has its own page with an image, a description, an ingredients list and step-by-step instructions.

## Recipes

| Recipe | Page |
| --- | --- |
| Paneer Butter Masala | `recipes/paneer-butter-masala.html` |
| Maggi | `recipes/maggi.html` |
| Burger | `recipes/Burger.html` |

## Project Structure

odin-recipes/

## What I Practiced

- Structuring a page with the HTML boilerplate
- Headings (`h1`–`h4`) and paragraphs
- Ordered and unordered lists
- Links between pages (relative paths such as `../index.html`)
- Adding images with the `img` tag and `alt` text

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/odin-recipes.git
   ```
2. Open the folder and double-click `index.html` in your browser.

No installation or build step is needed.
